# @nhatnguyet/festivals

Vietnamese festivals and holidays with lunar-to-solar dates for any year (206 festivals, CC BY 4.0 data).

This package is the English-named entry point of [`@nhatnguyet/le-hoi`](https://www.npmjs.com/package/@nhatnguyet/le-hoi) and re-exports exactly the same API (both names stay in sync; use whichever you prefer).

```bash
npm i @nhatnguyet/festivals
```

Full documentation, English API and examples: [@nhatnguyet/le-hoi](https://www.npmjs.com/package/@nhatnguyet/le-hoi) · [nhatnguyet.org/en/ma-nguon-mo](https://nhatnguyet.org/en/ma-nguon-mo) · [API docs](https://nhatnguyet.org/en/ma-nguon-mo/tai-lieu).

Data: Nhat Nguyet (nhatnguyet.org). MIT license.
