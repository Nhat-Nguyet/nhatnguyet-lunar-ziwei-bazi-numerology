# @nhatnguyet/fengshui

**Feng shui rules of traditional schools for JavaScript and TypeScript.**
Eight Mansions (Ba Zhai, Bát Trạch) life gua or Kua number and house gua, the
24 mountains of the compass, Xuan Kong (Huyền Không) flying star charts for
periods 1 to 9 with castle gates, annual stars, the three Luban rulers, and
SVG drawings of the compass and of a flying star chart. Names in English,
Chinese and Vietnamese. No third-party dependencies (it uses
`@nhatnguyet/am-lich` for the lunar year).

[![test cases: 3,083](https://img.shields.io/badge/test%20cases-3%2C083%20passing-2e7d32.svg)](../../../ca-kiem/README.md)

This is the TypeScript port of the feng shui engine behind
[nhatnguyet.org](https://nhatnguyet.org/en/ma-nguon-mo), checked field by field
against 3,083 test vectors generated by that engine
([`ca-kiem/fengshui.json`](../../../ca-kiem/fengshui.json)). The Python module
`nhatnguyet.fengshui` passes the same vectors and draws byte-identical SVG.

> **What this is, and what it is not.** These functions compute what the
> rules of a school say: which star a book puts in which direction, which
> number flies to which palace, which sector of a ruler a length falls in.
> They are traditional rules, not verified effects. No study has shown that a
> direction, a flying star or a measurement changes health, money or
> relationships. Where schools disagree, [docs/fengshui.md](../../../docs/fengshui.md)
> says so.

## Install

```bash
npm i @nhatnguyet/fengshui
```

## Quick start

```ts
import { lifeGua, houseGua, mountainAt, flyingStarChart, annualStars, periodOf, lubanRuler } from "@nhatnguyet/fengshui";

const g = lifeGua("1990-09-19", "female");
g.number;          // 8   (a female 5 becomes 8, a male 5 becomes 2)
g.trigram.name;    // "Gen"
g.group;           // "west"
g.element;         // "Earth"
g.directions.map((d) => `${d.direction} ${d.starName}`).join(", ");
// "southwest Sheng Qi, northwest Tian Yi, west Yan Nian, northeast Fu Wei,
//  south Huo Hai, east Liu Sha, north Wu Gui, southeast Jue Ming"

lifeGua("1990-01-20", "male").note;
// "Born before the lunar New Year, so the lunar year is 1989."

houseGua({ facing: 200 }).trigram.name;   // "Kan" (the house sits Gui, in the north)
mountainAt(7.5).name;                     // "Gui" (each sector includes its lower edge)

const c = flyingStarChart({ period: 9, facing: "wu" });
c.pattern;         // "double-sitting"
// mountain star, facing star / period star, south on top:
// 63/8 18/4 81/6 | 72/7 54/9 36/2 | 27/3 99/5 45/1

annualStars(2026).center;   // 1   (One White)
periodOf(2026).period;      // 9   (2024 to 2043)

lubanRuler(81, { ruler: "luban" }).sector.name;   // "Ben" (auspicious)
lubanRuler(80, { ruler: "luban" }).nearestAuspicious.map((x) => x.lengthCm);
// [69.7, 80.5]   (80 cm falls in Hai; the nearest good lengths below and above)
```

Every function takes `{ lang: "en" | "vi" | "zh", terms: "pinyin" | "han" | "vi" }`:

```ts
import { lifeGua } from "@nhatnguyet/fengshui";

lifeGua("1990-09-19", "female", { lang: "zh" }).trigram.name;            // "艮"
lifeGua("1990-09-19", "female", { lang: "vi" }).directions[0].starName;  // "Sinh Khí"
lifeGua("1990-09-19", "female", { terms: "han" }).directions[0].starName; // "生气"
```

## Drawings

```ts
import { lifeGua, flyingStarChart, renderCompassSvg, renderFlyingStarSvg } from "@nhatnguyet/fengshui";

renderCompassSvg({ gua: lifeGua("1990-09-19", "female"), facing: 180 });   // SVG: the 24 mountains, 8 trigrams and 8 stars
renderFlyingStarSvg(flyingStarChart({ period: 9, facing: "wu" }), { theme: "dark" });
```

Self-contained SVG strings (no fonts, images or scripts), `lang`, `terms`,
`theme: "light" | "dark"`, `width`. The compass is drawn south at the top, as
compass books draw it (`orientation: "north-up"` turns it).

## API

| Function | Returns |
|---|---|
| `lifeGua(birth, gender, opts?)` | Kua number, trigram, east or west group, element, eight directions. `birth` is a date (the lunar year turns at the lunar New Year, Vietnam time) or a lunar year number |
| `eightDirections(gua, opts?)` | the eight stars of a gua number (or of a `lifeGua` / `houseGua` result): direction, degrees, the three mountains, `starName`, `pinyin`, `han`, `nameVi`, `gloss`, `favorable` |
| `houseGua({ facing } or { sitting }, opts?)` | the house trigram (of the sitting side) and its eight directions |
| `trigramOf(number, opts?)` | trigram of a Lo Shu number |
| `mountains24(opts?)`, `mountainAt(degrees, opts?)`, `findMountain(nameOrDegrees, opts?)` | the 24 mountains: degrees, kind, direction, trigram, Three Cycles dragon, Xuan Kong polarity |
| `flyingStarChart({ period or year, facing or sitting }, opts?)` | base, mountain and facing stars of the nine palaces, the role (qi) of each star, the named pattern, castle gates |
| `annualStars(year, opts?)` | the annual flying stars (the year counts from the Start of Spring) |
| `periodOf(year)`, `periods(year)`, `nineStars()`, `starQi(period, star)` | the 20-year periods, the nine stars, the role of a star in a period |
| `lubanRuler(length, { ruler, unit })`, `lubanRulers()` | sector, sub-sector, good or bad group, nearest good lengths |
| `renderCompassSvg(opts)`, `renderFlyingStarSvg(chart, opts)` | SVG strings |

Years are 1900 to 2100. Invalid input throws a `RangeError` (out of range) or
a `TypeError` (wrong kind of value).

## Conventions

- **Year boundary.** The life gua uses the lunar year, turning at the lunar
  New Year (Tết) in Vietnam time, as the engine does. Books that turn the
  year at the Start of Spring (about 4 February) give another gua to people
  born between the two dates; pass the year number you want to follow them.
  Periods and annual stars count years from the Start of Spring.
- **Eight Mansions.** The order is the engine's: Sheng Qi, Tian Yi, Yan Nian,
  Fu Wei, then Huo Hai, Liu Sha, Wu Gui, Jue Ming. Star names are pinyin
  (they have no fixed English translation); `gloss` is a literal translation
  of the characters, not a reading.
- **Flying stars.** Shen school (沈氏玄空) rules for the plain facing.
  Replacement stars (替卦) for a facing near a mountain edge, and monthly
  stars, are not in the engine, so they are not here.
- **Mountains.** A sector includes its lower edge (Zi is 352.5 to 7.5).
  `xuanKongPolarity` is the Flying Star school's yin and yang; other schools
  assign it differently, and the engine gives no per-mountain element.
- **Luban rulers.** Equal sectors; a length exactly on an edge belongs to the
  upper sector; lengths are rounded to 0.1 mm. A sub-sector has `pinyin`
  and a literal English gloss `nameEn` (口舌 "Quarrels"); its `name` follows
  `terms` like every other name. The 38.8 cm ruler has no sub-sectors.
