# @nhatnguyet/ziwei

Zi Wei Dou Shu (Purple Star Astrology, 紫微斗数) charts on the Vietnamese or Chinese calendar: palaces, stars, Four Transformations, decade luck, patterns, SVG, iztro-compatible data.

This package is the English-named entry point of [`@nhatnguyet/tu-vi`](https://www.npmjs.com/package/@nhatnguyet/tu-vi) and re-exports exactly the same API (both names stay in sync; use whichever you prefer).

```bash
npm i @nhatnguyet/ziwei
```

Full documentation, English API and examples: [@nhatnguyet/tu-vi](https://www.npmjs.com/package/@nhatnguyet/tu-vi) · [nhatnguyet.org/en/ma-nguon-mo](https://nhatnguyet.org/en/ma-nguon-mo) · [API docs](https://nhatnguyet.org/en/ma-nguon-mo/tai-lieu).
