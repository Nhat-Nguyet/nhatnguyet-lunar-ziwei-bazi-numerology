# Knowledge units

Compact knowledge bases for developers and AI, one row per atomic unit of knowledge (a star in a palace, a day master by month, a number in a role), with the site's interpretation text in Vietnamese, English and Chinese, the public domain classical passages the reading engine looks up for the unit, and rule ids. Generated by the knowledge exporter of the Nhat Nguyet engine; each folder holds the Hugging Face card (`README.md`), `coverage.json`, and every table as Parquet (`data/`), JSON Lines (`jsonl/`) and CSV (`csv/`).

**These are the rules of traditional schools, not verified predictions.** Data: Nhat Nguyet (nhatnguyet.org), CC BY-NC 4.0 from 20 November 2026 (earlier releases: CC BY 4.0).
