# @nhatnguyet/bazi

BaZi (Four Pillars of Destiny, 八字) by solar term: pillars, hidden stems, Ten Gods, symbolic stars, luck periods, SVG.

This package is the English-named entry point of [`@nhatnguyet/bat-tu`](https://www.npmjs.com/package/@nhatnguyet/bat-tu) and re-exports exactly the same API (both names stay in sync; use whichever you prefer).

```bash
npm i @nhatnguyet/bazi
```

Full documentation, English API and examples: [@nhatnguyet/bat-tu](https://www.npmjs.com/package/@nhatnguyet/bat-tu) · [nhatnguyet.org/en/ma-nguon-mo](https://nhatnguyet.org/en/ma-nguon-mo) · [API docs](https://nhatnguyet.org/en/ma-nguon-mo/tai-lieu).
