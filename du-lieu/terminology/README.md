# Terminology: Vietnamese, Chinese and English names

Every term the Nhat Nguyet libraries output (stems, branches, the sixty pairs, elements,
na yin, the 24 solar terms, the 28 mansions, Zi Wei Dou Shu palaces, stars, rings,
brightness levels and patterns, BaZi Ten Gods, hidden-stem roles and symbolic stars,
numerology numbers, festival categories, the I Ching trigrams, 64 hexagrams, Eight
Palaces generations, six relations and six spirits, and the feng shui Eight Mansions
stars, 24 mountains, nine stars, flying star patterns and Luban ruler sectors), with its Vietnamese name, traditional and
simplified Chinese, tone-marked pinyin, the English name the libraries use, other English
renderings, and a short definition where the engine already has one.

Data: Nhat Nguyet (nhatnguyet.org). License: [CC BY 4.0](../../DATA-LICENSE).
Planned on Hugging Face as `nhatnguyet/terminology`.

- [`terminology.csv`](terminology.csv): one row per term, UTF-8, header row.
- [`terminology.json`](terminology.json): the same rows under `terms`, plus counts and
  descriptions per category.

## Columns

| Column | Meaning |
|---|---|
| `id` | Stable id: category plus the position in the category's own order (`ziwei-major-star-01` is Tử Vi, `solar-term-01` is Start of Spring) |
| `category` | One of the categories above |
| `vi` | Vietnamese name with diacritics, exactly as the libraries output it with `lang: "vi"` |
| `vi_alt` | Other Vietnamese spellings the core vocabulary knows (`Thuỷ` for `Thủy`, `Kim Bạch Kim` for `Kim Bạc Kim`), separated by `\|` |
| `han` | Traditional Chinese |
| `zh` | Simplified Chinese, exactly as the libraries output it with `lang: "zh"` |
| `pinyin` | Hanyu pinyin with tone marks, one syllable per character |
| `en` | The English name the libraries output with `lang: "en"` (default `terms: "pinyin"`) |
| `en_alt` | Other English renderings, separated by `\|`; `en_alt_source` says where each comes from, in the same order |
| `en_alt_source` | `terms: "vi"` (the Sino-Vietnamese form the libraries give with that option), `nhatnguyet core` (the Go engine's own English where the English layer corrects it), `iztro 2.6.5 (en-US)` (the iztro library's English strings) |
| `code` | The machine code the libraries use for the term where there is one (`jie`/`qi` for solar terms, `M`, `V`, `Đ`, `B`, `H` for brightness, bureau number, star group, festival dataset code) |
| `definition_en`, `definition_vi`, `definition_zh` | A short definition, only where the engine has one (solar-term meanings) or where it follows from the engine's own tables (element and polarity of a stem, hidden stems of a branch, na yin of a pair, the relation that defines each Ten God). Empty otherwise: no meaning is invented here |
| `note` | Rule or caveat in English: how a star is placed, how a symbolic star is looked up and where the books disagree, the quadrant and weekday of a mansion |
| `source` | The table in [`js/packages`](../../js/packages) the row is read from |

## How it is made, and why it cannot drift

[`generate.mjs`](generate.mjs) imports the TypeScript libraries and reads their own tables
(`TU_VUNG`, `TIET_KHI_TABLE`, `TEN_CUNG_THEO_OFFSET`, `SAO_PHU_THEM`, `allThapThan`,
`tinhThanSat`, `NUMEROLOGY_LABELS`, `allHexagrams`, `mountains24`, `lubanRulers`...). No
name the libraries already have is typed by hand. Traditional characters and pinyin are
composed character by character from [`han-readings.json`](han-readings.json), a
reviewed table of 401 characters (with the readings these terms take: 长 cháng in 长生,
相 xiàng in 天相 and 宰相, 曲 qǔ in 武曲, 宿 xiù in 寡宿, 参 shēn as a mansion, 辟 bì as a
Gua Qi rank); a traditional name the libraries carry themselves (Ten Gods, patterns,
the 64 hexagrams and the eight trigrams, which also carry their own tone-marked pinyin,
the Luban sectors) or that iztro's zh-TW strings give wins over it.

[`check.test.mjs`](check.test.mjs) runs two checks:

1. The committed CSV, JSON and the category table above equal a fresh generation, byte
   for byte. A library table that changes without regenerating fails.
2. **Every name the libraries actually output is in the glossary**, in all three
   languages. The test casts every Zi Wei and BaZi chart of the shared test vectors
   ([`ca-kiem`](../../ca-kiem)) with `lang` "vi", "en" and "zh", converts dates and lists
   solar terms from 1900 to 2100, builds all 60 pillars and 24 double hours, and reads
   the numerology labels and festival categories, every hexagram and trigram, a Six
   Lines chart and the daily hexagram of every I Ching test vector date, every life
   gua, the 24 mountains, every flying star chart of periods 1 to 9 and the three
   Luban rulers; any palace, star, brightness,
   transformation, bureau, pillar, Ten God, hidden-stem role, stage, symbolic star,
   hexagram, trigram, relation, spirit, mountain, star or sector name it meets must be a `vi`, `en` or `zh` value here. A name added to a library
   without a row here fails.

```bash
cd thu-vien-mo/js && npm install && cd ..           # once: links the packages
node --conditions=source du-lieu/terminology/generate.mjs           # write the files
node --conditions=source du-lieu/terminology/generate.mjs --check   # only check
node --conditions=source --test du-lieu/terminology/check.test.mjs
```

## Notes

- The English names of stems, branches and the sixty pairs are pinyin without tones, as
  English BaZi and Zi Wei books write them; `Wu` is both 戊 and 午, `Ji` both 己 and 忌,
  so use `zh` or `id` as a key, not `en`.
- Vietnam's fourth zodiac animal is the Cat (Mèo, 猫); with a country other than Vietnam
  the libraries return the Rabbit, which has its own row.
- The 28 mansions and their four quadrants have no Chinese in the libraries (they output
  Vietnamese and English); the standard Chinese names are added here and marked in
  `source`.
- The English names of the Eight Mansions stars, the 24 mountains and the Luban sectors
  are pinyin, as the libraries output them; `en_alt` of an Eight Mansions star is a
  literal translation of its characters (the `gloss` field), not a reading.
- Festival categories are codes in the festival dataset; with `lang` "vi" and "zh" the
  libraries return the code itself, so those rows have no Chinese.
- `en_alt` from iztro reproduces display strings of [iztro](https://github.com/SylarLong/iztro)
  2.6.5 (MIT license, Copyright (c) 2023 All Contributors), so users of that library can
  map its names to these.
