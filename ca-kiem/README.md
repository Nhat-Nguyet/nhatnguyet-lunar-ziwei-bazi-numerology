# Test vectors (`ca-kiem`)

17,291 core test vectors (28,586 including school options, auspicious hours, I Ching and feng shui), generated by the Nhat Nguyet reference engine. Any
implementation, in any language, passes when it reproduces every `ra` from its
`vao`. The TypeScript and Python ports in this repo pass all of them on every
push. The rules of the port challenge are in
[CONTRIBUTING.md](../CONTRIBUTING.md#port-challenge).

| File | Cases | What is computed |
|---|---:|---|
| `am-lich.json` | 14,936 | lunar calendar: Gregorian to lunar, lunar to Gregorian, the 24 solar terms of a year |
| `tu-vi.json` | 777 | Zi Wei Dou Shu chart, ten-year periods, the viewed year, transiting stars, patterns |
| `bat-tu.json` | 777 | BaZi four pillars, luck pillars, minor luck |
| `than-so-hoc.json` | 600 | Pythagorean numerology profile |
| `le-hoi.json` | 201 | Gregorian dates of the Vietnamese festivals in a year |

School options ([docs/schools.md](../docs/schools.md)), added in engine 2.2.0, kept apart
from the 17,291 core vectors above: each `vao` adds a `schools` object.

| File | Cases | What is computed |
|---|---:|---|
| `tu-vi-phai.json` | 352 | Zi Wei chart with `fireBell`, `leapMonth`, `transformations`, `heavenlyKitchen`, `injuryMessenger` (half of them leap-month births); `caveat` and `ghiChuGioTy` are kept in `ra` |
| `bat-tu-phai.json` | 80 | BaZi chart with `ziHour` (mostly 23:00 to 24:00 births) |

Other suites:

| File | Cases | What is computed |
|---|---:|---|
| `auspicious-hours.json` | 1,096 | the twelve double hours of a day: auspicious or not, presiding spirit |
| `fengshui.json` | 3,083 | feng shui rules: Eight Mansions life gua and house gua, the 24 mountains, Xuan Kong flying star charts (periods 1 to 9, 24 sitting mountains, castle gates), periods and annual stars, Luban rulers; the operations and keys are in [docs/fengshui.md](../docs/fengshui.md#test-vectors) |
| `iching.json` | 6,684 | I Ching: the 8 trigrams and 64 hexagrams (names, palace, world and response, nuclear, opposite, reversed), three-coin casts from given line values, Plum Blossom numbers, Six Lines (najia) charts on 489 dates, the Gua Qi daily hexagram on 5,675 days; the operations and keys are in [docs/iching.md](../docs/iching.md#test-vectors) |

The keys are Vietnamese because they are the keys of the reference engine;
this page translates every key a case uses. Names in the values (stems,
branches, stars, palaces) are Vietnamese too, with `...En` and `...Zh`
siblings where the engine provides them.

## Check your port

1. Read a case file and, for each `ca[i]`, compute the answer from `ca[i].vao`.
2. Print one JSON value per line (JSON Lines), in the same order as `ca`.
3. Compare (Python 3.8+, no dependencies):

```bash
./my-port ca-kiem/than-so-hoc.json > answers.jsonl
python3 ca-kiem/check.py ca-kiem/than-so-hoc.json answers.jsonl
# than-so-hoc: 600/600 passed
```

`check.py` drops the keys listed in `khoaBo`, compares deeply (key order does
not matter, arrays are ordered, floats within `1e-9`, `true` is not `1`),
prints the first 5 failures with their input and exits with 1 if any case
fails. The exact function call behind every `ra` is `tinh(vao)` in
[`python/tests/test_*.py`](../python/tests).

## File format

| Key | Meaning |
|---|---|
| `mon` | suite name (`am-lich`, `tu-vi`, ...) |
| `moTa` | description of the suite (Vietnamese) |
| `phienBanDongCo` | version of the reference engine that generated the cases |
| `khoaBo` | keys to drop on both sides before comparing (long explanatory texts) |
| `soCa` | number of cases |
| `ca` | the cases: `[{vao, ra}]` |
| `vao` | input of a case |
| `ra` | expected output of a case |

Invalid input (for example a gender that is neither `"Nam"` nor `"Nữ"`)
expects `{"loi": true}` (`loi` = error).

## Shared keys and values

| Key or value | Meaning |
|---|---|
| `dd`, `mm`, `yyyy` | Gregorian day, month, year of birth or of the date |
| `ngay`, `thang`, `nam` | day, month, year (lunar or Gregorian depending on the object) |
| `day`, `month`, `year`, `leap` | a date; `leap` is true for a leap (intercalary) lunar month |
| `gio`, `phut` | hour, minute (see each suite for the meaning of `gio`) |
| `gioiTinh` | gender: `"Nam"` = male, `"Nữ"` = female |
| `namXem` | the year being viewed (for yearly luck and personal year) |
| `hoTen` | full name |
| `can`, `chi` | heavenly stem, earthly branch |
| `canChi`, `label` | stem and branch together, e.g. `"Canh Ngọ"` |
| `canChiNam`, `canChiThang`, `canChiNgay` | year, month, day pillar (stem and branch) |
| `hanh` | element: `Kim` Metal, `Mộc` Wood, `Thủy` Water, `Hỏa` Fire, `Thổ` Earth |
| `napAm`, `napAmTen` | na yin element, na yin name (e.g. `"Lộ Bàng Thổ"`, Earth by the Roadside) |
| `"Âm"`, `"Dương"` (values) | yin, yang |
| `tietKhi` | solar term |
| `ten` | name |
| `viTri` | position: index of an earthly branch, 0 Tý (Rat) to 11 Hợi (Pig) |
| `tuoiMu` | East Asian age (1 at birth, +1 at each lunar new year) |
| `...En`, `...Zh` | the same field in English, in Simplified Chinese |

Earthly branches in order (index 0 to 11): Tý, Sửu, Dần, Mão, Thìn, Tỵ, Ngọ,
Mùi, Thân, Dậu, Tuất, Hợi. Heavenly stems: Giáp, Ất, Bính, Đinh, Mậu, Kỷ,
Canh, Tân, Nhâm, Quý.

## `am-lich.json` (lunar calendar)

`vao.phep` (operation) selects the case type.

| Key | Meaning |
|---|---|
| `phep: "duong-sang-am"` | Gregorian to lunar (`dd, mm, yyyy`), Vietnam time (UTC+7) |
| `phep: "am-sang-duong"` | lunar to Gregorian (`ngay, thang, nam, nhuan`) |
| `phep: "moc-tiet-khi"` | the 24 solar term moments of Gregorian year `nam`, to the minute, Vietnam time |
| `muiGio` | time zone in hours when not Vietnam: `8` China, `9` Korea and old Japanese calendar; `ra` is then only `{am}` or `{duong, hopLe}` |
| `nhuan` | the lunar month is a leap month |
| `am` | lunar date `{day, month, year, leap}` |
| `duong` | Gregorian date `{day, month, year}` (`0, 0, 0` when invalid) |
| `hopLe` | the lunar date exists |
| `saoNhiThapBatTu` | lunar mansion of the day (one of the 28) |
| `index` | solar term number, 0 Xuân Phân (Vernal Equinox) to 23 |
| `kinhDo` | solar longitude of the term, degrees |
| `laTiet` | sectional term (`true`, starts a BaZi month) or midpoint term (`false`) |
| `yNghia` | short meaning of the term |

## `tu-vi.json` (Zi Wei Dou Shu)

`vao`: `dd, mm, yyyy, gio, gioiTinh, namXem`; `gio` is the branch index of the
birth hour (0 Tý, 23:00 to 00:59, to 11 Hợi). `ra` is
`{laSo, daiVan, hanNam, saoLuu, cachCuc}`.

| Key | Meaning |
|---|---|
| `laSo` | the natal chart |
| `amDuongMenh` | yin-yang and gender, e.g. `"Dương Nam"` Yang Male |
| `banMenhNapAm` | na yin of the birth year |
| `cuc`, `tenCuc` | bureau number (2 to 6) and name, e.g. `"Thổ Ngũ Cục"` Earth Five |
| `cung` | the 12 palaces, in branch order from Tý |
| `tenCung` | palace name, e.g. `Mệnh` Life, `Phụ Mẫu` Parents, `Phu Thê` Spouse |
| `cungMenh`, `cungThan` | branch index of the Life palace and of the Body palace |
| `menhCungChi` | branch of the Life palace |
| `laThan` | this palace is also the Body palace |
| `tuanTrung`, `trietLo` | the palace is under Tuần (旬空) or Triệt (截空) |
| `gioSinh` | branch of the birth hour |
| `ngaySinhAm`, `ngaySinhDuong` | lunar and Gregorian birth date |
| `sao` | stars in a palace; in `hanNam` it is a star name |
| `loai` | star kind: `chinh-tinh` major, `phu-tinh` minor, `truong-sinh` Changsheng ring, `bac-sy` Boshi ring, `thai-tue` Suiqian ring |
| `mieuVuong` | brightness: `Miếu` exalted, `Vượng` prosperous, `Đắc` favorable, `Bình` neutral, `Hãm` weak |
| `tuHoa`, `hoa` | Four Transformations: `Hóa Lộc`, `Hóa Quyền`, `Hóa Khoa`, `Hóa Kỵ` |
| `daiVan` | ten-year periods: `thu` order, `tuTuoi`/`denTuoi` from age/to age, `chinhTinh` major stars of the palace |
| `hanNam` | the viewed year |
| `luuNienChi`, `luuNienTenCung`, `luuNienViTri` | yearly palace: branch, palace name, index |
| `tieuVanChi`, `tieuVanTenCung`, `tieuVanViTri` | minor limit of the year |
| `daiVanTuTuoi`, `daiVanDenTuoi`, `daiVanTenCung` | the ten-year period covering the year (0 and `""` before the first one) |
| `luuTuHoa` | the year's Four Transformations: `sao` star, `chiCung` palace branch, `coTrenLaSo` the star is on the chart |
| `nguyetHan` | monthly limits: `luuDauQuanChi`, `luuDauQuanViTri` (Đẩu Quân of the year), `thang` (month 1 to 12 with its palace) |
| `saoLuu` | transiting stars of the year: `ma` id (e.g. `luu-thai-tue`), `theoCan` placed by the year stem, `voiDaiVan`, `voiTieuVan`, `voiLuuNien` relation to that palace: `dong-cung` same palace, `tam-hop` trine, `xung-chieu` opposite, `""` none |
| `cachCuc` | patterns found: `ten` name, `tenHan` classical name, `nhom` group (`dinh-quy`, `dinh-phu`, `dinh-ban-tien`...), `dieuKien` the condition met, `moTa` description, `chuVan` original classical line, `chiCung` palace branch |
| `coDiBan` | schools read this pattern differently (a variant reading exists) |

## `bat-tu.json` (BaZi)

`vao`: `dd, mm, yyyy, gio, phut, gioiTinh, namXem`; `gio` and `phut` are the
clock time (0 to 23, 0 to 59), `gio` absent means the birth hour is unknown.
`ra` is `{laSo, tieuVan}`.

| Key | Meaning |
|---|---|
| `truNam`, `truThang`, `truNgay`, `truGio` | year, month, day, hour pillar |
| `canAm` | the stem is yin |
| `canHanh`, `chiHanh` | element of the stem, of the branch |
| `tangCan` | hidden stems of the branch; `vaiTro` role: `Bản khí` main qi, `Trung khí` middle qi, `Dư khí` residual qi |
| `thapThan`, `thapThanCan` | Ten God of a hidden stem, of the pillar stem (e.g. `Chính Quan` Direct Officer) |
| `truongSinh` | Twelve Stages of the day master on this branch |
| `tuToa` | Twelve Stages of the pillar's own stem on its branch |
| `thanSat` | symbolic stars; in `laSo` a list with `ten`, `chiDich` target branches, `viTri` pillars (0 year to 3 hour), `traTheo` how it is looked up, `loiKhac` other schools' rule |
| `nhatChu`, `nhatChuHanh`, `nhatChuAmDuong` | day master: stem, element, yin-yang |
| `menhCung` | life palace pillar (命宫) |
| `thaiNguyen` | conception pillar (胎元) |
| `namTruNam` | the year that the year pillar belongs to (the year turns at Lập Xuân, Start of Spring) |
| `ngaySinh` | birth date |
| `coGioSinh` | the hour is known |
| `tietKhi`, `tietDauThang` | solar term of the birth day, sectional term that opened the month |
| `daiVan` | luck pillars |
| `thuan` | luck runs forward (`true`) or backward |
| `lyDo` | why forward or backward |
| `tietMoc`, `tietMocNgay`, `tietMocGio`, `tietMocPhut` | the sectional term used to count the start, its date, hour, minute |
| `soNgay` | days from birth to that term |
| `tuoiKhoiNam`, `tuoiKhoiThang`, `ngayKhoiVan` | start of luck: years, months, date |
| `cacVan` | the luck pillars: `thuTu` order, `tuoiTu` from age, `namTu`/`namDen` from year/to year |
| `tieuVan` | minor luck of `namXem` |

## `than-so-hoc.json` (numerology)

`vao`: `hoTen, dd, mm, yyyy, namXem, thangXem, ngayXem` (the name and birth
date, then the viewed year, month, day).

| Key | Meaning |
|---|---|
| `soDuongDoi` | Life Path number |
| `soSuMenh` | Expression (Destiny) number |
| `soLinhHon` | Soul Urge number |
| `soNhanCach` | Personality number |
| `soNgaySinh` | Birthday number |
| `soThaiDo` | Attitude number |
| `soTruongThanh` | Maturity number |
| `soNamCaNhan`, `soThangCaNhan`, `soNgayCaNhan` | Personal Year, Month, Day |
| `soNoNghiepNgaySinh` | karmic debt number of the birth day (13, 14, 16, 19), absent if none |
| `soDinhCao` | Pinnacles: `dinh1` to `dinh4`, `tuoiKetThucDinh1` to `3` age each one ends |
| `soThachThuc` | Challenges: `thachThuc1` to `thachThuc4` |
| `luoiPythago` | Pythagoras grid: how many times each digit `1` to `9` appears in the birth date |

## `le-hoi.json` (festivals)

`vao`: `nam` (Gregorian year). `ra` is a list `[{id, ngay}]` in the order of
[`du-lieu/le-hoi-viet-nam.json`](../du-lieu): `id` is the festival id, `ngay`
its Gregorian date `"YYYY-MM-DD"` in that year.
