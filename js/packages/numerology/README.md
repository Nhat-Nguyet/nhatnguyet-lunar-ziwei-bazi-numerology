# @nhatnguyet/numerology

Pythagorean numerology with correct handling of Vietnamese names: life path, expression, soul urge, pinnacles, challenges, personal year, SVG.

This package is the English-named entry point of [`@nhatnguyet/than-so-hoc`](https://www.npmjs.com/package/@nhatnguyet/than-so-hoc) and re-exports exactly the same API (both names stay in sync; use whichever you prefer).

```bash
npm i @nhatnguyet/numerology
```

Full documentation, English API and examples: [@nhatnguyet/than-so-hoc](https://www.npmjs.com/package/@nhatnguyet/than-so-hoc) · [nhatnguyet.org/en/ma-nguon-mo](https://nhatnguyet.org/en/ma-nguon-mo) · [API docs](https://nhatnguyet.org/en/ma-nguon-mo/tai-lieu).
