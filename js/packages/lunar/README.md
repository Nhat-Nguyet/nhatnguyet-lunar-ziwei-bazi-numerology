# @nhatnguyet/lunar

Vietnamese lunar calendar (also Chinese, Korean, Japanese), sexagenary cycle, 24 solar terms within 1 minute of IMCCE, 28 lunar mansions.

This package is the English-named entry point of [`@nhatnguyet/am-lich`](https://www.npmjs.com/package/@nhatnguyet/am-lich) and re-exports exactly the same API (both names stay in sync; use whichever you prefer).

```bash
npm i @nhatnguyet/lunar
```

Full documentation, English API and examples: [@nhatnguyet/am-lich](https://www.npmjs.com/package/@nhatnguyet/am-lich) · [nhatnguyet.org/en/ma-nguon-mo](https://nhatnguyet.org/en/ma-nguon-mo) · [API docs](https://nhatnguyet.org/en/ma-nguon-mo/tai-lieu).
